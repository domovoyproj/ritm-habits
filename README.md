# Ритм

Ежедневный трекер привычек с календарём и статистикой. Помогает отмечать небольшие действия, видеть последовательность и возвращаться после пропуска без обнуления всей истории.

## Возможности

- Свои привычки с пояснением, значком и цветом.
- Отметки за сегодня и прошедшие дни начиная с даты создания привычки.
- Просмотр недели и месячный календарь с интенсивностью выполнения.
- Процент выполненного плана, недельные итоги и текущие серии.
- Редактирование, удаление, локальное сохранение и перенос через JSON.
- Адаптивная верстка и доступные с клавиатуры элементы управления.

## Как считается серия

Если привычка ещё не отмечена сегодня, серия считается от вчерашнего дня. После сегодняшней отметки он добавляется к серии. Пропуск вчерашнего дня прерывает текущую серию, но не удаляет прошлые отметки. Даты используют локальный календарь устройства, а не UTC.

Статистика прошедшего дня учитывает только привычки, которые уже существовали на ту дату. Все привычки ежедневные. Недельные итоги всегда относятся к текущей неделе, независимо от открытой даты.

## Запуск

Нужен Node.js 20+. Внешние пакеты не требуются.

```sh
npm start
npm test
```

Локальный адрес: http://127.0.0.1:4173. Переменная PORT меняет порт. На статический хостинг публикуется содержимое dist/.

## Данные

Привычки и история хранятся в localStorage. Между устройствами автоматической синхронизации нет. Экспортируйте резервную копию перед очисткой браузера. Импорт проверяет формат и заменяет данные после подтверждения. Удаление привычки удаляет и её историю после подтверждения.

## Структура

- dist/model.js — серии, календарные недели, прогресс и валидация.
- dist/app.js — отображение, формы и обработчики.
- dist/shared.js — локальные даты, хранение и резервные копии.
- tests/ — проверки серий, переходов года и високосного дня.
